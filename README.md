# Bill Tracker

A personal bill tracker in a single HTML file. Open `index.html` in any browser.

- Add, edit, delete bills (name, amount, due date, category, paid/unpaid, notes)
- Overdue, due in 7 days and total unpaid at a glance
- Search, filter by status/category, sort by due date, amount, name or category
- Data is saved in the browser on each device; use Export/Import backup to move it

Can be hosted for free with GitHub Pages (Settings → Pages → deploy from `main`).
